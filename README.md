# INCONNU CHECK BAN

A web app (packaged into an Android APK via Capacitor) that checks whether a WhatsApp number is banned. The app relies on a free public API, hosted on Render:

**https://inconnu-check-ban-api.onrender.com**

**Open source project** — feel free to fork it, change the design, swap the images, rename it, and build your own APK.

## How the API works

The app sends a `POST` request to the API every time a number is checked. No API key is needed on the app side — the API is free and ready to use directly.

### Check a number

```
POST https://inconnu-check-ban-api.onrender.com/check
Content-Type: application/json
```

**Request body:**

```json
{
  "number": "+2250000000000"
}
```

**Response:**

```json
{
  "banned": false,
  "reason": null
}
```

- `banned` → `true` if the number is banned, otherwise `false`
- `reason` → an explanation if available, otherwise `null`

In the app's code, this is handled here (`inconnuboy/index.html`):

```js
const PROXY_URL = 'https://inconnu-check-ban-api.onrender.com/check';

const _r = await fetch(PROXY_URL, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ number: num })
});
const _d = await _r.json();
const _banned = _d.banned === true;
const _reason = _d.reason || '';
```

If you're building your own app or website from this repo, you can call this same URL directly.

```bash
npm install

npx cap open android      # opens Android Studio to build/sign/test
```

## Automatic build via GitHub Actions

The `.github/workflows/build-apk.yml` workflow:

- triggers on every `push` to `main` (or manually from the **Actions** tab)
- installs Node + JDK 17
- adds the Android platform if it's missing
- generates the Android icons from `android-icons/logo-source.png`
- builds a **debug APK** (unsigned, not for the Play Store, but installable directly on a phone)
- uploads the APK as a downloadable artifact under **Actions → run → Artifacts**

This is the easiest way to get your APK after modifying the project: push to `main`, wait for the workflow to finish, then download the artifact.

## Customizing the app

There are two ways to customize the app: **from inside the app** (quick, but not permanent for everyone) and **in the source code** (permanent, seen by anyone who installs the APK).

### 1. From inside the app (no code needed)

Once the app is open:

- **Change the displayed name**: tap the title at the top of the app (or menu ☰ → *Edit name*). ⚠️ This change isn't saved — it resets to the default name on reload or app restart. For a permanent change, edit the source code (see below).
- **Change the images** (cube icon + background): menu ☰ → **Settings** (⚙) → *Choose an image* for the cube and the background. These images are saved on the device (local storage) and persist across app restarts, but only on that specific device.
- **Change the messages** shown when a number is banned / not banned: same Settings screen, *Ban message* / *OK message* fields.
- **Change the visual theme**, toggle animations and the animated background: also in Settings.
- A **Reset** button restores everything to default.

### 2. In the source code (permanent, for everyone)

Everything lives in `inconnuboy/index.html`. The most useful things to change:

| What you want to change | Where to find it in `index.html` |
|---|---|
| Tab title / app name | `<title>` tag (top of the file) |
| Icon (favicon, PWA) | `<link rel="icon">` and `<link rel="apple-touch-icon">` tags |
| Default image (cube + background) | search for `https://files.catbox.moe/wf2uxn.jpg` — replace with your own image link |
| Default displayed name | `<div class="title" id="titleEl">INCONNU CHECK BAN</div>` |
| WhatsApp channel link | `var LINK_WHATSAPP = '...'` |
| GitHub / support link | `var LINK_GITHUB = '...'` |
| Android app name / package (`appId`) | `capacitor.config.json` (`appName`, `appId`) — do this **before** the first `npx cap add android` |
| Android icon (all resolutions) | replace `android-icons/logo-source.png` with your own logo — the workflow regenerates every size automatically on the next build |

After editing the code, rebuild the APK either locally (`npx cap sync android` then build), or by pushing to `main` and letting GitHub Actions do it.
